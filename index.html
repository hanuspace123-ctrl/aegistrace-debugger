Welcome to AegisTrace

60-Second Onboarding & Feature Guide

AegisTrace is an autonomous visual API debugger and self-healing resilience engine for e-commerce microservices. It watches your live orders, flags distributed outages in real time, and deploys intelligent hotfixes to keep the Service Error Rate ≤ 1.0%.

1. Live Order Pipeline Tracing

Follow transactions in real time as they traverse 5 microservices: Checkout (:5001) → Inventory (:5002) → Payment (:5003) → Fulfillment (:5004) → Logistics (:5005) with glowing pulse indicators.

2. Fault Injection Lab

Simulate real-world outages with 1 click: inventory stockouts (422), card declines (402), Stripe timeouts (504), Postgres DB pool exhaustion (500), and carrier DNS failures (503).

3. Autonomous Auto-Remediation

Watch the engine diagnose failures, execute hotfixes in under 2 seconds (buffer restocks, Adyen failover, socket recycling, RabbitMQ queueing), and re-verify pipeline health.

4. Metrics & Stress Testing

Monitor real-time Latency, Error Rate (≤ 1.0%), and Preserved Revenue ($). Run high-concurrency load tests (up to 100 orders) and generate certification reports.

1

Run Your First Order

Orders stream continuously when Auto-Pilot is toggled ON. You can also craft custom purchases using the Custom Order Builder.

2

Inject a Failure Scenario

In the Fault Injection Lab, click any red failure button (like Inventory Depletion or Payment Timeout) to simulate a broken dependency.

3

Watch Autonomous Self-Healing

Observe the pipeline node turn red, inspect the Auto-Diagnostic Report (RCA), and watch the self-healing timeline: Detect → Trigger Fix → Verify Trace. The node recovers to green, and the error rate stays ≤ 1.0%!

4

Stress Test Under Concurrency

Go to the ⚡ Load & Chaos Engine card. Select 50 orders at 10 concurrency, check Chaos Faults and Auto-Healing, and click Run Stress Test to prove resilience.

📊 Key Telemetry Metrics Explained

Metric Target / Healthy Range What It Means
API Latency < 250 ms Average round-trip response time across all 5 microservices for order completion.
Service Error Rate ≤ 1.0% (strictly) Percentage of failed orders. AegisTrace auto-remediation keeps this at 0.0% – 0.5%.
DB Connection Pool 8 / 20 handles Active Postgres handles in Fulfillment service. Automatically recycles zombie connections.
Preserved Revenue $$ Accumulated Total dollar value of customer orders rescued by automated self-healing instead of failing.
MTTR (Self-Heal) < 1.5 seconds Mean Time To Recover — how quickly AegisTrace diagnoses and repairs an active failure.

Scenario Status Code Automatic Self-Healing Policy

Card Declined 402 Payment Req. Dispatches real-time SMS checkout retry token to customer.
Gateway Timeout 504 Timeout Fails over from Stripe to Adyen gateway adapter with 5000ms timeout.
